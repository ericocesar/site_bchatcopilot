# Animação do SVG

## Objetivo da animação

* [ ] Mostrar claramente que os cards avançam entre etapas do Kanban
* [ ] Demonstrar automação empresarial em funcionamento
* [ ] Fazer o quadro parecer vivo e operacional

## Fluxo animado

* [ ] Animar o avanço de pelo menos 1 card entre as colunas
* [ ] Fluxo mínimo:

  * `NOVO LEAD` → `QUALIFICADO`
  * `QUALIFICADO` → `NEGOCIAÇÃO`
  * `NEGOCIAÇÃO` → `CONCLUSÃO`
* [ ] O card pode ser o mesmo card progredindo entre etapas, ou cards encadeados que simulem continuidade
* [ ] Ao iniciar cada transição:

  * destacar o card ativo
  * iluminar a coluna de origem
  * animar uma conexão/trilha entre origem e destino
* [ ] Ao concluir a transição:

  * encaixar o card na posição final
  * destacar brevemente a nova coluna
  * emitir um glow/pulso sutil no destino

## Comportamento visual

* [ ] O movimento dos cards deve ser suave
* [ ] Duração sugerida por movimento: entre `1.8s` e `3s`
* [ ] Loop infinito
* [ ] Intervalo breve entre cada transição
* [ ] Easing suave
* [ ] Evitar animações agressivas ou chamativas demais
* [ ] Adicionar microefeitos:

  * trilha luminosa durante o movimento
  * brilho sutil no card ativo
  * leve pulso de status ao chegar na coluna de destino

## Técnicas

* [ ] Implementar o quadro como SVG animado
* [ ] Preferir animação com:

  * CSS no próprio componente
  * ou SMIL (`animate`, `animateTransform`)
  * ou transformações controladas por CSS/JS leves
* [ ] Evitar dependências pesadas apenas para essa animação
* [ ] Se houver JavaScript, mantê-lo mínimo
